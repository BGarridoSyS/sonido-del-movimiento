# El sonido del movimiento
Recorrido interactivo de «El sonido del movimiento», exposición de sismología, música y mapping de Bastián I. Garrido Kogan. Vista general y POV de un niño y de un adulto, los seis momentos (de Tren Tren y Caicai Vilu a la pandemia), el proceso de creación, los artistas y las referencias.

Sitio: https://bgarridosys.github.io/sonido-del-movimiento/
